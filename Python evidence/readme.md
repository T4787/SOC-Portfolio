# Projects
This folder showcases projects built in python. 

- Hangman.py
  >> Hangman.py was created following a basic tutorial, which created the basic game with one category as an array. I built on this tutorial by adding more complex functionality, including adding more categories using an object, which randomly get selected at the start of a game. Additionally, I added a restart the game function at the end with hints about the category selected for each round. This taught me how to take the skills I learnt in the basic CFG python kick starter into a project that showcases some basic Python skills. You play this by opening the game in a terminal and following the instructions displayed in the terminal.
